# Сегментація дороги для НРК (нічна ІЧ-камера)

Нейромережа знаходить на кожному кадрі відео **дорогу від краю до краю** (один клас: дорога / не дорога),
малює її краї й центральну лінію і рахує:
- **напрямок дороги попереду** (кут, + = праворуч),
- **ширину дороги** біля машини (частка ширини кадру),
- **зсув машини від центру дороги** (+ = машина лівіше центру),
- **впевненість** моделі; якщо низька (дощ, засвітка, дороги не видно) — показує `LOW CONFIDENCE`
  і не видає напрямок.

Мета проєкту — основа для утримання руху НРК уздовж дороги. **Керування (кут керма) ще не реалізоване** —
зараз є лише сприйняття дороги й геометрія.

---

## Швидкий старт: запустити готову модель на відео

Інтернет потрібен лише для встановлення бібліотек. Colab / Google Drive для запуску **не потрібні**.

### 1. Встановлення

Linux / macOS:
```bash
git clone https://github.com/tkachukvlad2007-source/def_hacaton.git && cd def_hacaton/road_seg
python3 -m venv .venv && source .venv/bin/activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu   # без NVIDIA GPU
pip install -r requirements.txt
```
Windows (PowerShell): те саме, але активація — `.venv\Scripts\Activate.ps1`.
З NVIDIA GPU — встанови torch за командою з https://pytorch.org (буде значно швидше).

### 2. Модель

Файл моделі **не зберігається в git**. Скачай `road_seg.pt` з розділу **Releases** цього репозиторію
і поклади в `models/road_seg.pt`.

### 3. Запуск

```bash
python seg_video.py відео.mp4 --model models/road_seg.pt --show     # вікно наживо, Q — вийти
python seg_video.py відео.mp4 --model models/road_seg.pt            # записати results/<назва>_road.mp4
python seg_video.py папка_з_відео/ --model models/road_seg.pt       # усі відео з папки
python seg_video.py 0 --model models/road_seg.pt --show             # жива камера (0 = перша)
```

| Параметр | За замовч. | Що означає |
|---|---|---|
| `--min-conf` | 0.6 | нижче — кадр позначається `LOW CONFIDENCE` (**поріг ще не відкалібровано**) |
| `--thr` | 0.5 | поріг ймовірності «дорога» для маски |
| `--smooth` | 0.5 | згладжування маски в часі (0 = вимкнено) |
| `--max-width` | 960 | кадр зменшується до цієї ширини перед обробкою |
| `--no-save` | — | не записувати відео (лише `--show`) |

Наприкінці кожного відео друкується: скільки кадрів оброблено, на скількох знайдено дорогу,
частка кадрів з низькою впевненістю, медіана впевненості.

## Технічні деталі (для того, хто продовжує роботу)

**Модель.** `segmentation_models_pytorch.Unet(encoder_name="mobilenet_v2", classes=1)`, 1 вихід (логіт «дорога»).
Версія бібліотеки **`segmentation-models-pytorch==0.5.0`** — інша версія може не завантажити ваги.

**Вхід.** Кадр → сірий → повторюється в 3 канали → нормалізація ImageNet → розмір **512×288** (ширина×висота,
кратні 32). Функція `preprocess()` у `train_seg.py`.

**Файл моделі** (`torch.save` словника):
```python
{"state": state_dict, "encoder": "mobilenet_v2", "size": [512, 288], "iou": 0.932, "val_videos": ["dev_0010"]}
```
Завантаження — `load_model()` у `seg_video.py`.

**Постобробка** (`seg_video.py`): згладжування ймовірностей у часі → поріг → закриття дірок →
лишається одна зв'язна область, що торкається низу кадру по центру (`keep_road`) →
краї й центр по 40 рядках, поліном 2-го ступеня по центру (`road_geometry`).

**Впевненість** (`confidence`): середнє `|2p−1|` у зоні дороги (наскільки ймовірності близькі до 0/1),
помножене на стабільність маски між сусідніми кадрами (IoU з попередньою маскою). Згладжується в часі.
На синтетиці: чітка маска ≈ 0.98, шум ≈ 0.24. **На реальних відео поріг не калібрувався.**

**Формат даних для навчання:**
```
data/images/<відео>__<номер_кадру>.jpg
data/masks/<відео>__<номер_кадру>.png      # 0 = не дорога, 255 = дорога
data/masks/_polygons.json                  # контури з label_tool.py (точки), щоб можна було редагувати
```
Префікс до `__` — назва відео. За ним `train_seg.py` ділить дані на навчання / перевірку **по відео**
(не по кадрах — інакше оцінка завищена). Кадри організаторів мають префікс `given__`.

**Розмітка організаторів** (`seg-*.zip`, папки `frames/` і `markdown/`): кольори масок
рожевий (255,0,255 BGR) = дорога, синій = небо, блакитний = трава/кущі, жовтий = дерева/стовпи.
Беремо лише рожевий.

**Навчання** (Colab T4, ~5 хв на 20 епох; перша епоха повільна через читання з Drive):
```bash
python train_seg.py --data data --out models/road_seg.pt --epochs 20 --batch 16 --val-videos dev_0010
```
Loss = BCE + Dice, AdamW, косинусний LR, аугментації під нічну камеру (яскравість/контраст/гамма,
пляма ІЧ-підсвітки, віньєтка, розмиття, змазування від трясіння, шум, поворот/зсув/масштаб, віддзеркалення).
Зберігається лише найкраща за IoU перевірки епоха. На наших даних плато настає після ~7 епох.

**Розмітник** (`label_tool.py`): ЛКМ — точка / тягнути точку, Ctrl+ЛКМ — вставити точку в сторону,
ПКМ — видалити, Enter — зберегти, C — копія попереднього контуру, R — скинути, E — дороги немає,
S — пропустити, B — назад, Q — вийти. Наступний кадр отримує контур попереднього. Відкривається з першого
кадру без маски; `--start N` — з кадру N (з нуля). Кожен Enter одразу пише маску на диск.
На Ubuntu (Wayland) попередження Qt про шрифти — нешкідливі.

## Відомі проблеми і що робити далі

1. **Дощ / засвітка.** Модель не бачила таких кадрів. Варіанти: розмітити ~20 кадрів з дощових відео
   (дорогу, де її видно; `E` — де не видно) і донавчити; додати аугментацію крапель/смуг.
   Не намагатися «вгадувати» дорогу там, де її не бачить людина — правильна поведінка: низька впевненість.
2. **Калібрування `--min-conf`.** Порівняти розподіл впевненості на чистому (`dev_0005`) і дощовому
   (`dev_0012`) відео, вибрати поріг між ними.
3. **Швидкість на борту.** Виміряти fps на цільовому комп'ютері НРК. Якщо мало — менший вхід (`--size` при
   навчанні, напр. 384×224), експорт в ONNX / TensorRT.
4. **Керування.** З `offset` і `angle` зробити регулятор (напр. `кермо = k1·angle + k2·offset`)
   і віддавати команду на контролер; при `LOW CONFIDENCE` — сповільнення / зупинка.
5. **Колії всередині дороги** (окремий клас) — якщо треба їхати саме по коліях, а не по центру дороги.

Швидке донавчання: навчити модель → `prelabel.py` на нових кадрах → покласти результат у
`data/masks/_prelabels.json` → `label_tool.py` покаже авто-контури (позначка AUTO), людина лише виправляє.
