# def_hacaton — комп'ютерний зір для наземного робота (хакатон УКУ, жовтень 2026)

| Папка | Що там |
|---|---|
| [`road_seg/`](road_seg/README.md) | сегментація дороги на нічному ІЧ-відео (U-Net MobileNetV2), автопілот `control.py`, симуляція втрати зв'язку `drive_sim.py`, стрес-тести погоди |
| [`road_seg/SEG3_README.md`](road_seg/SEG3_README.md) | задача 2 (нова метрика 23.10): сегментація на 3 класи дорога / рослинність / перешкода (`train_mc.py`, `predict_mc.py`), авто-розмітка відео `autolabel.py`, ансамбль + постобробка `make_inference.sh`, mIoU 0.867 за офіційним `eval.py` |
| [`guard/`](guard/README.md) | задача 3: напівавтономність «круїз + виявлення дронів над маршрутом», карта маршруту з GPS/IMU/відео, детектор дронів YOLO11n, стоп перед перешкодою на шляху (`obstacles.py`) |
| [`ALGORITHMS.md`](ALGORITHMS.md) | як це все працює простими словами: які алгоритми, як навчали, як визначає дорогу / перешкоди / дрони, чому саме так |

Гілка `vlad-version` — робота Влада; `road-seg` — початкова сегментація (Захар).
Моделі (`*.pt`), відео й дані в git не зберігаються — див. README кожної папки.
Список того, що треба зробити далі, — у `guard/README.md`, розділ «Що треба зробити далі».
